# NLP Internship Projects 🚀

This repository contains all the Natural Language Processing (NLP) tasks completed during my **Data Science Internship (February 2026)**.
Each task demonstrates different stages of building real-world NLP systems — from preprocessing to transformer-based models.

---

## 📌 Tasks Overview

### 🔹 Task 1: NLP Preprocessing Engine

* Built a robust preprocessing pipeline
* Removed noise (URLs, numbers, special characters)
* Handled repeated characters and spacing
* Token analysis and statistics
* Designed reusable preprocessing functions

---

### 🔹 Task 2: Sentiment Analysis using ML Models

* Applied full NLP pipeline:

  * Text cleaning
  * Tokenization
  * Stopword removal
  * Lemmatization
* Feature Engineering:

  * Bag of Words (BoW)
  * TF-IDF
* Models implemented:

  * Logistic Regression
  * Naive Bayes
  * Decision Tree
* Compared models using:

  * Accuracy
  * Precision
  * Recall
  * F1 Score
* Visualized model performance
* Tested custom input predictions

---

### 🔹 Task 3: Chatbot using Transformers

* Built an interactive chatbot using Hugging Face Transformers
* Used pre-trained model (DialoGPT)
* Implemented:

  * Dynamic response generation
  * Continuous conversation flow
  * Exit conditions
* Simulated real conversational AI system

---

### 🔹 Task 4: BERT Fine-Tuning

* Fine-tuned **BERT (bert-base-uncased)** for sentiment classification
* Performed:

  * Tokenization
  * Dataset preparation
  * Model training using PyTorch
* Evaluated using:

  * Accuracy
  * Precision
  * Recall
  * F1 Score
  * Confusion Matrix
* Experiments:

  * Full fine-tuning
  * Frozen BERT layers
  * Fine-tuning last layers
* Compared performance across strategies

---

### 🔹 Task 5: NLP Token Classification

* Implemented token-level classification pipeline
* Applied NLP preprocessing techniques
* Built structured output for token predictions
* Handled edge cases and text variations

---
